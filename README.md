# PolyMentor Website

React guide site for the PolyMentor / PolyCode ecosystem — setup, platform overview, MLOps, deployment, and long-term vision.

## Routes

- `/` — Overview and architecture
- `/setup` — Clone repos, configure env, run PolyCode + PolyMentor
- `/polycode` — What PolyCode is and how it connects to the mentor
- `/mlops` — Extract → train → evaluate → deploy, plus GitHub Actions and GPU worker notes
- `/deploy` — Production deployment for PolyCode and custom model inference
- `/vision` — SENODROOM roadmap and concepts covered

## Commands

```bash
npm install
npm run dev
npm run build
```

Dev server: **http://localhost:5173**
